# Developer 2: Simple Guide

## What I will do

I will build and check the dashboard, execution graph, recovery timeline, Chaos Lab, metrics, styling, and demo instructions. I will use the backend contract so the screen shows real run data.

## What you need to do

1. Open this project in VS Code.
2. You do not need to install Python, Node.js, React, or npm packages for this work.
3. Jac is already installed in this workspace. You can check it in the terminal:

   ```sh
   jac --version
   ```

4. Wait until I say the app is ready, then start it from the project folder:

   ```sh
   jac install
   jac start --dev
   ```

5. Open the local address printed in the terminal and try the demo.
